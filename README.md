# 妙手回春模拟器

王者荣耀世界「画盘」玩法的竖屏单页复刻小游戏（同人二创，非官方）。

打开 `index.html` 即玩，**单文件自包含**（立绘与背景图以 base64 内嵌），零依赖、离线可用。

---

## 玩法

选一支画笔颜色 → 点棋盘任意一格 → **该格所在的整片连通同色区域全部变成画笔色**。
在「剩余步数」耗尽前，把 63 格全部恢复成目标色即通关。

- 棋盘：9 列 × 7 行 = 63 格，四色（红 / 黄 / 蓝 / 绿）
- 点「已经是该画笔色」的区域不会消耗步数（防手滑）
- 染色带泼溅扩散动画，从点击格向外逐格蔓延

## 两个模式

| 模式 | 内容 | 说明 |
|---|---|---|
| 修炼模式 | 30 个固定关卡 | 棋盘为程序生成的**图形化布局**（条纹 / L 型 / X 型 / 回字 / 十字 / 棋盘格 / 镜像 / Z 型 / 斜带 / 散点），前 2 关好上手，第 3 关起**零富余步数** |
| 世界模式 | 16 关 | 复刻原游戏画盘-1 ~ 画盘-16 的真实关卡与官方步数，含每关最优解数据 |

关卡**通关解锁下一关**；进度、已通关标记、最高分都存在本地。

## 特色功能

- **师姐教程**：首次进入自动弹出 6 步引导（聚光灯逐项高亮），顶栏「?」可重播
- **师姐助力**：同一关失败满 3 次，自动 +2 步（步数旁出现「师姐助力 +2」徽章）
- **彩蛋**：**连点师姐立绘 3 下**，弹出本关最优解 —— 「点第 X 行第 Y 列那一格，一直点它，画笔按 红 → 蓝 → 绿 换」，关掉后该格白光闪烁指路
- **失败不打断**：步数耗尽只弹一句「步数耗尽，已重置画盘」并自动重置本盘
- 选关面板：显示当前模式与总关数，数字方块点选（已通关绿色、未解锁上锁）

> 最优解不是估算：修炼关卡由 BFS 求解器算出真最优；世界关卡直接使用官方路线图数据。

## 目录结构

```
├── index.html                  成品：单文件游戏（双击即玩）
├── build.py                    重建：template + 素材 + 关卡数据 -> index.html
├── src/
│   ├── template.html           游戏模板（含 __B64_FULL__ / __B64_BG__ / __TRAIN_LEVELS__ 占位符）
│   ├── train_levels.js         修炼 30 关数据（含最优解 tap/seq）
│   ├── world_levels.js         世界 1~13 关数据
│   └── world_levels_14_16.js   世界 14~16 关数据（从路线图提取）
├── assets/
│   ├── shijie_full*.png        师姐立绘（原尺寸 / 网页用量化版）
│   ├── shijie_head*.png        头像裁切
│   ├── bg.jpg                  背景图（游戏内原画）
│   └── world_src/              14~16 关的路线图原图（提取用）
├── tools/
│   ├── prep_art.py             立绘白底去背 + 缩放量化
│   ├── gen_train2.py           修炼关卡图形化生成器（10 种图形 + 难度校准 + 求解）
│   ├── gen_train.py            修炼关卡早期随机生成器（留档）
│   ├── extract_world.py        从路线图提取棋盘（五帧链条自检 + 求解器确认）
│   └── fix_world.py            把世界关卡数据安全写回模板
└── qa/                         Playwright 自动化验收脚本（_qa2 ~ _qa8）
```

## 如何重建

```bash
python build.py          # 由 src + assets 生成 index.html
```

## 如何验收

验收脚本用 Playwright（`playwright-core`）驱动真实浏览器，覆盖：教程、重置、失败重置、师姐助力、最优解重放、模式切换、选关解锁、关卡数据正确性等。

```bash
node qa/_qa8.js          # 例：世界 14~16 关按最优解重放必须恰好通关
```

脚本内的路径为写死的工作目录，跑之前把 `process.env.TEMP + '/峡谷画盘_build/index.html'` 改成你本地的 `index.html` 路径即可。

## 数据来源与致谢

- 世界模式 1~13 关：来自配套项目 [coloring-board-puzzle](https://github.com/yogurt8888/coloring-board-puzzle) 的关卡索引（BFS 求解器验证过最优性）
- 世界模式 14~16 关：从三张通关路线图逐格提取，经「五帧链条自检 + 重放尺寸比对 + 求解器确认」三重验证
- 修炼模式 30 关：`tools/gen_train2.py` 生成，每关最优步数由求解器给出
